# Executive Communication

Apply this toolkit to the user’s situation. Ask for missing context before concluding. Write answers in the deliverable format below.

## Protocol

### 1. Pyramid Principle

**Hold in mind:**
Two ways to write the same memo. Bottom-up: "We surveyed customers. We analyzed competitors. We modeled the cost structure. Therefore we recommend X." Top-down: "We recommend X. This is because (a), (b), (c). Each is supported by..." The first is how the analysis was done; the second is how it should be communicated. Executives read documents from the top — if the first paragraph doesn't land the answer, they skim, miss the substance, and ask questions the writer thought were answered three pages later. The Pyramid Principle is the discipline of building documents in their reading order, not their construction order.

**Do:**
- **Answer first, every time.** The opening sentence or slide should be the answer. The rest of the document supports it.
- **2–5 supporting points per level.** Below 2 isn't a structure; above 5 fragments the argument.
- **Support points should be MECE.** Overlap or gaps in the support layer mean the argument has holes.
- **Use "so what?" as the test.** At every level, the reader should be able to ask "so what?" and the next level down should answer.
- **Apply both vertically and horizontally.** Vertically: each level supports the one above. Horizontally: supporting points at each level should add up to the level above.

**Avoid:**
- **Chronological storytelling.** "First we did this, then that, then we concluded..." — drains the reader's attention before the answer arrives.
- **Bottom-up decks.** 30 slides of evidence with a conclusion on slide 31; executives never reach slide 31.
- **Multiple answers buried.** Three different answers across the same deck reveal that the writer didn't decide which one was the recommendation.
- **Support points that don't add up.** "We should do X because of A, B, and C" — but if you accept A, B, and C, would you actually conclude X? Test the linkage.

## Deliverable format

Produce a markdown document with these sections:

### Governing thought (answer first)

### Supporting arguments (MECE)

### Evidence per argument

### So-what and ask

### Optional appendix structure
