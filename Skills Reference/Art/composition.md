# Composition / Visual Hierarchy

**Category:** [Art](../../docs/deck.html) &nbsp;|&nbsp; **[← Card Deck](../../docs/deck.html)**

---
## Definition

Composition, or visual hierarchy, is the deliberate arrangement of elements in a visual or informational space so that attention flows in an intended order — what is seen first, second, and last — governed by placement, scale, alignment, grouping, and negative space, not by content importance alone. It is distinct from Contrast: contrast is the mechanism that makes one element read as different from its neighbors, while composition is the spatial logic that decides where that difference is placed and what it ends up being compared against. A high-contrast element in the wrong position still fails to direct attention correctly.

---

## Mental Model

An experienced practitioner treats the page, screen, or room as a field with a small number of entry points and a directional flow, and designs deliberately which element the eye lands on first and where it travels next. Four levers do almost all of the work: position (in Western reading order, top-left carries default primacy), scale (larger reads as more important, independent of true importance), proximity (grouped elements read as related; separated elements read as distinct categories), and negative space (space around an element amplifies its importance more reliably than making the element louder).

Composition is invisible when it's good — the audience simply understands "this is the point, here's the support" without noticing the architecture that produced that read. When it's absent, every element competes for attention with none winning, and everything reads as equally, unhelpfully important.

---

## Practitioner Heuristics

- **Identify the single entry point before placing anything else.** Every composition needs one, and only one, obvious "start here" — decide it first, then build everything else around it.
- **Use proximity and whitespace to signal grouping before reaching for color or borders.** Groups read as related through space alone; borders and color are a fallback, not a first tool.
- **Check the scan path, not just the elements.** Trace where the eye actually goes in the first three seconds. If it doesn't match the intended reading order, the composition is wrong regardless of how good any individual element is.
- **Give the most important element the most negative space, not the loudest treatment.** Isolation reads as importance more reliably than size or color once a composition already has some contrast in it.
- **Design the hierarchy before the content is final.** Retrofitting hierarchy onto a wall of equally-weighted content produces a compromise; designing from the hierarchy outward produces clarity.

---

## Common Failure Modes

- **Democracy of elements.** Giving every element roughly equal visual weight because everything feels important to the person who made it — the reader receives no guidance and disengages.
- **Confusing decoration with hierarchy.** Adding visual noise (borders, icons, extra color) to signal importance instead of using placement and space, producing clutter that competes with the content it was meant to elevate.
- **Hierarchy that doesn't match the actual argument.** Placing the most visually prominent position on a secondary point because it was easier to design, burying the actual conclusion in a visually subordinate position.
- **Ignoring the scan path across cultures or contexts.** Assuming a reading order that doesn't hold for the actual audience or medium, so the intended first entry point isn't the audience's actual first entry point.

---

## Worked Example

A one-page investment memo has five sections drafted with identical formatting: same font size, same margins, no visual differentiation. The recommendation — "Approve, subject to three conditions" — sits in paragraph four, syntactically identical to the market-sizing paragraph above it.

A redesign applies composition discipline: the recommendation moves to a headline position at the top, isolated in its own block with generous whitespace above and below it — negative space signaling primacy. Supporting sections are grouped under clear subheadings with tighter internal spacing — proximity signaling "these belong together." A single callout box holds the three conditions, visually separated from the narrative prose. The content is unchanged; the reader now reaches the recommendation in the first five seconds instead of on the third read-through.
